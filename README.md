# notification-gateway-demo

A static demo of a notification gateway's client dashboard. Every number, name and message is invented, any password signs in,
and nothing is ever sent. The browser answers the API itself (a service worker), so there is no server behind this site.

Open: https://nasibulloh.github.io/notification-gateway-demo/ (sign in as `demo` for a client's person, `onboarding` for a client that has not finished its setup, `admin` for platform staff).

This repository holds only the built site.
